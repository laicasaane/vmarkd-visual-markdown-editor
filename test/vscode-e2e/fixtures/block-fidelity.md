# Block fidelity

TYPE-HERE anchor paragraph.

An indented code block, the CommonMark form that legacy and pandoc documents use:

    indented code line
    second indented line

A second one, whose content holds a fence of its own:

    ```
    inner fence
    ```

Prose between the blocks, so the ones above are not the first or last thing here.

A titled reference link: [the reference][ref], and a titled image reference:
![the image][imgref].

A definition with no title at all: [plain][plainref].

[ref]: https://example.com "Ref Title"
[imgref]: pic.png 'Image Title'
[plainref]: https://plain.example
